# Proxmox 仮想基盤 基本設計書（抜粋）

版数: 1.0.0  
作成日: 2025-12-30  
作成者: Nickelth

## 1. システム構成概要

### 1.1 物理構成

| 要素 | 内容 |
|---|---|
| ホスト名 | proxmox-host01 |
| 役割 | 仮想基盤ホスト |
| CPU  | 8 コアクラス（Intel Core i7 / Ryzen 5） |
| メモリ | 32GB |
| ストレージ | SSD 1TB（Proxmox / VM 兼用）|
| NIC | 1GbE x1（自宅ルータに接続）|

### 1.2 論理構成

- ハイパーバイザ: Proxmox VE 最新安定版
- 管理ネットワーク: 自宅 LAN と共通（vmbr0）
- ゲスト OS:
  - VM-WIN11-01: Windows 11 Pro
  - 将来: VM-LINUX-01（Ubuntu Server 等）

## 2. ネットワーク設計

### 2.1 セグメント構成

- 自宅 LAN: 192.168.10.0/24
- ルータ: 192.168.10.1
- Proxmox ホスト: 192.168.10.10
- Windows 11 VM: 192.168.10.20（固定 IP）

### 2.2 論理構成図（簡易）

自宅ルータ  
　└─ Proxmox ホスト（vmbr0）  
　　　└─ Windows 11 VM（RDP 受け）  

VPN クライアント（外出先）  
　└─ VPN サーバー（ルータ or Linux VM）  
　　　└─ 自宅 LAN 経由で 192.168.10.20 に RDP

### 2.3 ポート設計

- RDP: 3389/tcp（LAN 内のみ）
- VPN: WireGuard もしくは OpenVPN（ポート番号はルータ側で定義）
- Proxmox 管理画面: 8006/tcp（LAN 内からのみアクセス可）

## 3. VM 設計

### 3.1 Windows 11 VM 設計

| 項目 | 設定値 |
|---|---|
| VM 名 | VM-WIN11-01 |
| vCPU | 4 |
| メモリ | 8GB（将来 16GB まで増設可）|
| システムディスク | 200GB（thin provisioning）|
| NIC | virtio-net, ブリッジ vmbr0 |
| OS | Windows 11 Pro |
| バックアップ | 日次スナップショット + 週次フル |

### 3.2 バックアップ設計

- バックアップ先:
  - 外付け HDD or NAS（SMB／NFS）
- ポリシー:
  - 日次増分バックアップを 7 日分保持
  - 週次フルバックアップを 4 週分保持
- リストア手順:
  1. Proxmox から対象バックアップを選択
  2. 同名 VM にリストアするか、新規 VM としてリストア
  3. 接続テスト後、旧 VM を廃止

## 4. 運用設計

### 4.1 監視・ログ

- 最低限の監視:
  - Proxmox Web UI にて CPU / メモリ / ストレージ使用率を確認
  - Windows イベントログの重大エラー確認
- 将来:
  - 外部監視ツール導入を検討（Zabbix / Grafana + Prometheus 等）

### 4.2 保守ルール

- 変更管理:
  - VM の構成変更（CPU・メモリ・ディスク）は事前にメモに記録
  - Proxmox バージョンアップ前にスナップショット取得
- 障害時対応:
  - まず VM の再起動、それで改善しない場合はバックアップからの復旧を検討
