## 1. 可用性

### NFR-AV-001 稼働時間
- 目標稼働時間: 平日 8:00〜22:00
- 計画停止: 月 1 回まで、1 時間以内（OS 更新・Proxmox 更新に使用）

### NFR-AV-002 故障復旧目標
- Windows 11 VM 障害時の復旧時間目標 (RTO): 4 時間以内
- 復旧ポイント目標 (RPO): 前日 23:00 時点のバックアップ

## 2. 性能・拡張性

### NFR-PE-001 Windows 11 VM の性能
- 同時利用ユーザー: 1 名
- ブラウザ・Office・IDE を併用しても体感ストレスが小さいこと
- 目安:
  - RDP 接続の画面遅延: 通常操作で気にならない程度
  - CPU 使用率: 平常時 70% 未満（VM 内）

### NFR-PE-002 拡張性
- Proxmox 上に Windows 11 VM 1 台 + Linux VM 1〜2 台を増設しても、
  物理サーバーのメモリ使用率が 80% を超えない構成とする。
- ストレージは将来 SSD を追加できるよう、ベイ／ポートに空きを残す。

## 3. 運用・保守性

### NFR-OP-001 バックアップ運用
- バックアップ種別: VM 単位のスナップショット + 外部ディスクへの定期バックアップ
- 頻度:
  - スナップショット: 毎日 23:00
  - 外部ディスク: 週 1 回（自動 or 手動）

### NFR-OP-002 手順書
- 以下の手順書を整備する：
  - Proxmox ホスト再起動手順
  - Windows 11 VM 再作成／復旧手順
  - バックアップ取得・リストア手順
- 手順書は Markdown でリポジトリ管理し、変更履歴を残す。

## 4. セキュリティ

### NFR-SE-001 ネットワーク境界
- 自宅外からのアクセスは VPN 経由のみ許可し、直接 RDP ポートはインターネットに公開しない。
- VPN 認証は ID／パスワード + 事前共有鍵を最低条件とする。

### NFR-SE-002 OS・ソフトウェア更新
- Windows Update: 月 1 回以上、セキュリティアップデートを適用
- Proxmox・ホスト OS: 四半期に 1 回程度、安定版に更新（事前にスナップショット取得）

## 5. 移行性

### NFR-MI-001 データ移行
- 既存物理 PC のユーザーデータ（ドキュメント／ピクチャ／デスクトップ配下）を、
  OneDrive などのクラウドストレージ経由、または共有フォルダ経由で VM に移行する。
- 移行作業は 1 日以内に完了することを目標とする。

## 6. 環境条件

### NFR-EN-001 設置環境
- 設置場所: 自宅室内、温度 10〜30℃ 程度、常時エアフローが確保される位置
- 電源: 無停電電源装置（UPS）導入を検討（将来要件）
