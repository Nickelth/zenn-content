## 1. 概要

### 1.1 プロジェクト名称
Proxmox を用いた社内仮想基盤構築および Windows 11 業務端末の仮想化

### 1.2 背景
現状、業務で利用している Windows PC は物理端末として運用しており、  
以下の課題がある。

- 端末故障時に復旧時間が長い（再セットアップに 1 日以上）
- 拠点外からの安全なリモート接続手段が確立されていない
- 将来的に Linux サーバーや検証用 VM を追加したいが、  
  物理マシンをこれ以上増やしたくない

これらの課題を解消するため、Proxmox VE による仮想基盤を構築し、  
Windows 11 業務端末を VM として集約する。

### 1.3 目的
- 業務用 Windows 端末の仮想化により、故障時の復旧時間を短縮する
- 自宅外から VPN 経由で安全に業務環境へアクセスできるようにする
- 1 台の物理サーバー上で複数 VM を運用し、将来の検証環境増設に備える

### 1.4 スコープ
本プロジェクトの対象範囲は以下とする。

- Proxmox VE を用いた仮想基盤の設計・構築
- Windows 11 VM（1 台）の設計・構築
- VPN 経由でのリモート接続方式の検討・試験
- 既存業務データ（ドキュメント類）の移行
- 運用手順書の作成（バックアップ・復旧・VM 追加手順）

以下はスコープ外とする。

- 商用サポート契約の締結
- 監視ツールの本格導入（Zabbix, Prometheus 等）
- AD ドメイン構成、SSO などの大規模認証基盤整備

## 3. 業務要件（機能要件）

### 3.1 業務シナリオ

- 利用者は、自宅 LAN 内から Windows 11 VM にリモートデスクトップ接続し、
  Office／ブラウザ／開発ツールを利用できること
- 利用者は、自宅外（実家・出先）から VPN 接続を行い、  
  自宅 LAN 内と同様に Windows 11 VM を利用できること
- VM は日次バックアップが取得され、障害時に前日夜の状態に戻せること

### 3.2 機能要件一覧

| ID | 要件区分 | 要件内容 |
|---|---|---|
| FUN-001 | 仮想基盤 | Proxmox VE 上に VM を作成・起動・停止できること |
| FUN-002 | VM | Windows 11 Pro ベースの VM を 1 台以上作成できること |
| FUN-003 | 接続 | LAN 内から RDP 接続で Windows 11 VM を利用できること |
| FUN-004 | 接続 | VPN 経由で RDP 接続が可能であること |
| FUN-005 | バックアップ | VM 単位でのバックアップ／リストアが可能であること |
| FUN-006 | 拡張 | 将来的に Linux サーバー VM を追加できること |

## 4. 非機能要件（概要）

詳細は「非機能要件定義書」を参照。概要のみ記載する。

| 区分 | 概要  |
|---|---|
| 可用性 | 業務時間帯（平日 8:00〜22:00）の稼働 |
| 性能・拡張性 | Windows 11 VM がストレスなく動作 |
| 運用・保守性 | バックアップ／復旧手順が 1 人で実行可能 |
| セキュリティ | VPN 経由のみ外部アクセス許可 |
| 移行性 | 既存データの移行手順を定義 |

## 5. システム構成（概要）

- 物理サーバー: 自宅内 PC（CPU: 8 コア程度, メモリ: 32GB, SSD 1TB）
- ハイパーバイザ: Proxmox VE 最新安定版
- VM:
  - Windows 11 Pro VM x1（メモリ 8〜16GB, vCPU 4 コア程度）
  - 将来拡張用 Linux VM（未作成、設計のみ）
- ネットワーク:
  - 自宅ルータ（NAT）
  - Proxmox ブリッジ（vmbr0）と LAN を接続
  - VPN サーバー：ルータまたは Linux VM 側で実装（方式は別途検討）
